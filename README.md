# Isometric Turn-Based Game

A simple isometric turn-based combat game developed in JavaScript.

## Running the Project

To run this project locally, you need Node.js and npm (or npx) installed.

1.  Navigate to the project's root directory in your terminal.
2.  Run the following command to start a simple local development server:

    ```bash
    npx serve .
    ```
3.  Open your web browser and go to the URL provided by the `serve` command (usually `http://localhost:3000` or similar).
